# Редиректы

## Назначение

Проверить и оптимизировать все редиректы в приложении, убедиться в их корректной работе и добавить недостающие.

## Задачи

- [ ] Проверить все редиректы в приложении
- [ ] Убедиться, что редиректы работают корректно после действий
- [ ] Оптимизировать редиректы (использовать Next.js router вместо window.location)
- [ ] Добавить редиректы где необходимо

## Файлы для работы

- `middleware.ts` - middleware редиректы
- `modules/processes/auth/model/AuthSlice.ts` - редиректы после auth действий

## Места для проверки

### Аутентификация
- После логина
- После регистрации
- После выхода
- При отсутствии доступа

### Навигация
- После создания поста
- После отправки сообщения
- После обновления профиля
- После удаления контента

### Middleware
- Защищенные роуты
- Редиректы для неавторизованных пользователей
- Редиректы для авторизованных пользователей на публичные страницы

## Оптимизация

- Использовать `useRouter()` из Next.js вместо `window.location`
- Использовать `redirect()` из Next.js для server-side редиректов
- Добавить правильные HTTP статус коды (301, 302, 307, 308)
