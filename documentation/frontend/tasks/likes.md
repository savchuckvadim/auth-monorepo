## Оптимистичные обновления

### Текущая реализация
- Запрос отправляется на сервер
- UI обновляется после получения ответа

### Целевая реализация
- UI обновляется сразу при клике
- Запрос отправляется в фоне
- При ошибке - откат изменений

### Пример реализации
```typescript
const handleLike = async () => {
    // Оптимистичное обновление
    dispatch(optimisticLike(postId));

    try {
        await postService.likePost(postId);
    } catch (error) {
        // Откат при ошибке
        dispatch(rollbackLike(postId));
    }
};
```
