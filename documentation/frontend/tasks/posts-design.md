# Доработка постов в соответствии с дизайном

## Назначение

Привести UI постов в соответствие с дизайном из Figma, добавить недостающие элементы, анимации и адаптировать под мобильные устройства.

## Задачи

- [ ] Проверить соответствие UI постов дизайну из Figma
- [ ] Реализовать недостающие элементы дизайна
- [ ] Добавить анимации и переходы согласно дизайну
- [ ] Адаптировать под мобильные устройства

## Файлы для работы

- `modules/entities/post/ui/Post/` - компоненты постов
- `modules/features/post/CreatePost/` - создание поста

## Компоненты для проверки

- `Post.tsx` - основной компонент поста
- `PostHeader.tsx` - заголовок поста (автор, дата)
- `PostContent.tsx` - содержимое поста (текст, медиа)
- `PostActions.tsx` - действия (лайки, комментарии, репосты)
- `PostFooter.tsx` - подвал поста
- `CreatePost.tsx` - форма создания поста

## Элементы дизайна для проверки

- Цвета и типографика
- Отступы и spacing
- Размеры элементов
- Иконки и их расположение
- Состояния (hover, active, disabled)
- Анимации переходов

## Мобильная адаптация

- Адаптивная верстка для разных размеров экранов
- Оптимизация для touch-интерфейсов
- Оптимизация загрузки изображений на мобильных
