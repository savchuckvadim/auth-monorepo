# Тестирование

## Назначение

Добавить тесты для критичных компонентов и основных flow приложения.

## Задачи

- [ ] Добавить unit тесты для критичных компонентов
- [ ] Добавить integration тесты для основных flow
- [ ] Добавить E2E тесты для ключевых сценариев

## Unit тесты

### Инструменты
- `@testing-library/react` - для тестирования React компонентов
- `@testing-library/jest-dom` - дополнительные матчеры
- `vitest` или `jest` - test runner

### Компоненты для тестирования
- Критичные компоненты:
  - `Post.tsx` - компонент поста
  - `MessageItem.tsx` - компонент сообщения
  - `CreatePost.tsx` - создание поста
  - `LoginForm.tsx` - форма логина
  - `ChatInputWidget.tsx` - ввод сообщения

### Что тестировать
- Рендеринг компонентов
- Обработка событий (клики, ввод)
- Условный рендеринг
- Props валидация

## Integration тесты

### Инструменты
- `@testing-library/react` для интеграционных тестов
- Моки для API и WebSocket

### Flow для тестирования
- Аутентификация (логин, регистрация, выход)
- Создание поста
- Отправка сообщения
- Лайк поста
- Подписка на пользователя

### Что тестировать
- Взаимодействие компонентов
- Работа с API
- Обновление состояния
- Навигация

## E2E тесты

### Инструменты
- `Playwright` или `Cypress` - для E2E тестирования
- Настройка тестового окружения

### Сценарии для тестирования
- Полный flow регистрации и первого входа
- Создание и публикация поста
- Отправка сообщения в чате
- Просмотр ленты новостей
- Профиль пользователя

### Что тестировать
- Полный пользовательский flow
- Работа в реальном браузере
- Взаимодействие с backend
- Навигация между страницами

## Настройка тестов

### Структура
```
__tests__/
├── unit/
│   ├── components/
│   └── hooks/
├── integration/
│   └── flows/
└── e2e/
    └── scenarios/
```

### Конфигурация
- `vitest.config.ts` или `jest.config.js`
- Настройка моков
- Настройка тестового окружения

## Покрытие тестами

- Цель: минимум 70% покрытия для критичных компонентов
- Использовать инструменты для отслеживания покрытия
- Регулярно обновлять тесты при изменении кода
