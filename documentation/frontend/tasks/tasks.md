# Задачи Frontend

## Приоритетные задачи

### 1. Создание дизайн-системы

**Назначение**: Создать централизованную дизайн-систему для обеспечения единообразия UI компонентов и стилей во всем приложении.

**Что нужно сделать**:
- [ ] Создать новый пакет `packages/design-system/` в монорепо
- [ ] Вынести все UI компоненты из `packages/ui/` в дизайн-систему
- [ ] Создать документацию компонентов (Storybook или аналогичный инструмент)
- [ ] Определить токены дизайна (цвета, типографика, spacing, shadows и т.д.)
- [ ] Создать систему тем (light/dark)
- [ ] Обеспечить переиспользование компонентов между проектами
- [ ] Добавить примеры использования каждого компонента
- [ ] Настроить сборку и публикацию пакета

**Структура пакета**:
```
packages/design-system/
├── src/
│   ├── components/      # UI компоненты
│   ├── tokens/          # Дизайн-токены (цвета, типографика)
│   ├── themes/          # Темы (light/dark)
│   ├── utils/           # Утилиты
│   └── index.ts         # Public API
├── stories/             # Storybook stories (опционально)
├── package.json
└── README.md
```

**Преимущества**:
- Единообразие UI во всем приложении
- Переиспользование компонентов
- Упрощение поддержки и обновлений
- Возможность использования в других проектах

**Файлы для работы**:
- `packages/ui/` - текущие UI компоненты (можно использовать как основу)
- `packages/theme/` - текущая тема (можно интегрировать)
