# Загрузка документов в посты и сообщения

## Назначение

Добавить возможность прикреплять документы (PDF, DOC, DOCX, TXT и т.д.) к постам и сообщениям.

## Требования

- Специальные кнопки для прикрепления файлов в мессенджере
- Ограничения по размеру и типам файлов
- Превью документов
- Скачивание документов

## Ограничения

### Размер файла

- Максимальный размер: **50 MB** на файл
- Для сообщений: можно прикрепить до 5 файлов одновременно
- Для постов: можно прикрепить до 10 файлов одновременно

### Разрешенные типы файлов

- Документы: `.pdf`, `.doc`, `.docx`, `.txt`, `.rtf`, `.odt`
- Таблицы: `.xls`, `.xlsx`, `.csv`, `.ods`
- Презентации: `.ppt`, `.pptx`, `.odp`
- Архивы: `.zip`, `.rar`, `.7z` (максимум 100 MB для архивов)
- Изображения: `.jpg`, `.jpeg`, `.png`, `.gif`, `.webp` (если не используется как изображение поста)
- Аудио: `.mp3`, `.ogg`, `.wav` (если не используется как аудиозапись)
- Видео: `.mp4`, `.webm`, `.mov` (максимум 200 MB для видео)

### 2. Валидация файлов

```typescript
const validateFile = (file: File): ValidationResult => {
    // Проверка типа
    const allowedTypes = ['application/pdf', 'application/msword', ...];
    if (!allowedTypes.includes(file.type)) {
        return { valid: false, error: 'Неподдерживаемый тип файла' };
    }

    // Проверка размера
    const maxSize = 50 * 1024 * 1024; // 50 MB
    if (file.size > maxSize) {
        return { valid: false, error: 'Файл слишком большой (максимум 50 MB)' };
    }

    return { valid: true };
};
```

## UI компоненты

### FileUploadButton

- Иконка бумажной скрепки или облака
- При клике открывает диалог выбора файлов
- Поддерживает множественный выбор
- Показывает ограничения (размер, количество)

### FilePreview

- Для изображений: миниатюра
- Для документов: иконка типа файла + название + размер
- Кнопка удаления
- Прогресс загрузки

### FileList

- Список всех прикрепленных файлов
- Возможность удаления
- Показ ошибок валидации
