## Улучшить типизацию

### Текущее состояние
- TypeScript strict mode не включен
- Некоторые типы не строгие (any, unknown)

### Целевое состояние
- Включить strict mode в `tsconfig.json`
- Убрать все `any` типы
- Добавить явные типы где необходимо

### Настройки TypeScript
```json
{
  "compilerOptions": {
    "strict": true,
    "noImplicitAny": true,
    "strictNullChecks": true,
    "strictFunctionTypes": true,
    "noUnusedLocals": true,
    "noUnusedParameters": true
  }
}
```

### Файлы для работы
- `tsconfig.json` - настройки TypeScript
- Все `.ts` и `.tsx` файлы - добавить типы
