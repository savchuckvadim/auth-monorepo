## Drag-and-drop для загрузки файлов

### Функциональность
- Перетаскивание файлов в область загрузки
- Визуальная обратная связь при перетаскивании
- Поддержка множественных файлов

### Компоненты
- `FileDropZone.tsx` - компонент для drag-and-drop
- Интеграция в `CreatePost.tsx` и `ChatInputWidget.tsx`

### Ограничения
- Те же ограничения, что и для обычной загрузки файлов
- Валидация типов и размеров файлов
