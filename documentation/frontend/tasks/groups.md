# Функционал групп

## Назначение

Создать функционал групп (публичные и закрытые) по аналогии с ВКонтакте. Группа выглядит как профиль с постами, может иметь групповой чат, поддерживает теги и фильтрацию. После переезда на LiveKit расширить функционал звонков до групповых.

## Зависимости

**Важно**: Эта задача должна выполняться **после** задачи [Переход чатов с WebRTC на LiveKit](./livekit-migration.md), так как требует групповых звонков через LiveKit.

**Связанная backend задача**: См. [Backend задача по группам](../../backend/tasks/groups.md)

## Требования

### Основные функции

1. **Типы групп**:
   - Публичные группы - видят все пользователи
   - Закрытые группы - видят только участники

2. **Структура группы**:
   - Группа выглядит как профиль с постами
   - У группы есть название, описание, аватар, hero изображение
   - У группы может быть или не быть групповой чат

3. **Навигация**:
   - Nav item "Группы" в главном меню
   - Фильтры: "Все", "Где я участник", "Где я админ"
   - Фильтр по тегам групп

4. **Теги групп**:
   - У каждой группы есть основной тег (категория/тема)
   - Фильтрация групп по тегам
   - Поиск групп по тегам

5. **Оповещения**:
   - Оповещения о постах в группах работают как для обычных постов
   - Оповещения о сообщениях в групповых чатах работают как для обычных сообщений

6. **Групповые звонки** (после LiveKit):
   - Возможность создавать групповые звонки в группах
   - Поддержка нескольких участников в одном звонке

## Детальная реализация

### 1. Типы групп

```typescript
enum GroupVisibility {
    PUBLIC = 'public',      // Публичная - видят все
    PRIVATE = 'private'     // Закрытая - видят только участники
}

enum GroupMemberRole {
    ADMIN = 'admin',        // Администратор
    MODERATOR = 'moderator', // Модератор
    MEMBER = 'member'       // Участник
}

interface Group {
    id: string;
    name: string;
    description?: string;
    avatar?: string;
    hero?: string;
    visibility: GroupVisibility;
    tag: string;                          // Основной тег группы
    hasChat: boolean;                     // Есть ли групповой чат
    chatId?: string;                      // ID группового чата (если есть)
    membersCount: number;
    postsCount: number;
    createdAt: Date;
    updatedAt: Date;
    // Отношения
    ownerId: string;                      // Создатель группы
    owner?: User;
    members?: GroupMember[];
    posts?: Post[];
}
```

### 2. Навигация "Группы"

**Расположение**: В главном меню приложения

**Фильтры**:
- "Все" - все группы (для публичных) или все доступные пользователю
- "Где я участник" - группы, где пользователь является участником
- "Где я админ" - группы, где пользователь является администратором

**Компонент**: `GroupsNavigationWidget`
- Показывает список групп с фильтрами
- Поиск по названию группы
- Фильтр по тегам

### 3. Страница группы

**URL**: `/network/groups/[groupId]`

**Структура** (как профиль):
- `GroupHeader` - аватар, название, описание, hero изображение
- `GroupInfo` - информация о группе (количество участников, постов, дата создания)
- `GroupActions` - кнопки действий:
  - "Присоединиться" / "Покинуть группу"
  - "Настройки" (только для админов)
  - "Групповой чат" (если есть)
  - "Создать звонок" (после LiveKit)
- `GroupPosts` - посты группы (использует существующий компонент постов)

### 4. Теги групп

**Структура**:
```typescript
interface GroupTag {
    id: string;
    name: string;
    slug: string;                         // URL-friendly версия
    description?: string;
    groupsCount?: number;                 // Количество групп с этим тегом
}

// Предопределенные теги (можно расширять)
const GROUP_TAGS = [
    'technology',
    'music',
    'sports',
    'gaming',
    'art',
    'education',
    'business',
    'entertainment',
    'news',
    'other'
];
```

**Фильтрация**:
- Компонент `GroupFiltersWidget` с выбором тегов
- Множественный выбор тегов
- Поиск групп по тегам

### 5. Групповой чат

**Условие**: Группа может иметь или не иметь групповой чат

**Если есть чат**:
- Использовать существующую структуру `Chat` с типом `GROUP`
- Связать группу с чатом через `group.chatId`
- Использовать существующие компоненты чата
- Оповещения работают как для обычных сообщений

**Компоненты**:
- `GroupChat.tsx` - обертка над существующим `ChatMessagesWidget`
- URL: `/network/groups/[groupId]/chat`

### 6. Посты в группах

**Использование существующей структуры**:
- Расширить модель `Post` для поддержки групп
- Добавить поле `groupId?: string` в Post
- Если `groupId` есть, пост принадлежит группе
- Использовать существующие компоненты постов

**Отображение**:
- На странице группы показывать только посты этой группы
- В ленте новостей показывать посты из групп, где пользователь участник
- Оповещения работают как для обычных постов

### 7. Групповые звонки (после LiveKit)

**Требования**:
- Возможность создать групповой звонок в группе
- Поддержка нескольких участников (3+)
- Использовать LiveKit для групповых звонков

**Реализация**:
- Расширить `CallWrapper` для поддержки групповых звонков
- Использовать `roomName = group-${groupId}` для групповых звонков
- UI для отображения нескольких участников в одном звонке
- Кнопка "Создать звонок" на странице группы (для участников)

**Компоненты**:
- Использовать `VideoConference` из LiveKit для групповых звонков
- Адаптировать `CallControls` для групповых звонков
