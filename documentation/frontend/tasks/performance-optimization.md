# Оптимизация производительности

## Назначение

Оптимизировать производительность приложения: рендеринг списков, мемоизация компонентов, загрузка изображений и WebSocket соединения.

## Задачи

- [ ] Оптимизировать рендеринг списков (виртуализация)
- [ ] Добавить мемоизацию компонентов
- [ ] Оптимизировать загрузку изображений (lazy loading)
- [ ] Оптимизировать WebSocket соединения

## Виртуализация списков

### Проблема
- Большие списки (посты, сообщения, пользователи) рендерят все элементы сразу
- Медленная прокрутка и большой расход памяти

### Решение
- Использовать библиотеки виртуализации:
  - `react-window` или `react-virtualized` для списков
  - `@tanstack/react-virtual` для виртуализации

### Компоненты для оптимизации
- Список постов в ленте
- Список сообщений в чате
- Список пользователей
- Список чатов

## Мемоизация компонентов

### React.memo
- Обернуть компоненты, которые редко меняются
- Передавать стабильные props

### useMemo и useCallback
- Мемоизировать вычисляемые значения
- Мемоизировать функции-колбэки

### Компоненты для мемоизации
- `Post.tsx` - компонент поста
- `MessageItem.tsx` - компонент сообщения
- `UserCard.tsx` - карточка пользователя

## Lazy loading изображений

### Next.js Image
- Использовать `next/image` для оптимизации изображений
- Автоматическое lazy loading
- Оптимизация размеров

### Intersection Observer
- Загружать изображения только при приближении к viewport
- Placeholder пока изображение загружается

### Компоненты
- Изображения в постах
- Аватары пользователей
- Медиа в сообщениях

## Оптимизация WebSocket

### Проблемы
- Множественные подключения
- Неоптимальная подписка на события
- Утечки памяти при отписке

### Решения
- Единое подключение через socketManager
- Правильная очистка подписок в useEffect cleanup
- Дебаунсинг для частых событий

### Файлы для оптимизации
- `modules/shared/lib/socket/` - socket менеджер
- Все хуки, использующие WebSocket

## Метрики для отслеживания

- Время первого рендера (FCP)
- Время до интерактивности (TTI)
- Размер бандла
- Производительность рендеринга (React DevTools Profiler)
