# Отправка поста в сообщении

## Назначение

Добавить возможность отправлять посты в сообщениях, с UI для выбора поста и отображением поста в сообщении.

## Задачи

- [ ] Добавить возможность отправить пост в сообщении
- [ ] Реализовать UI для выбора поста и отправки
- [ ] Добавить отображение поста в сообщении
- [ ] Реализовать переход к посту из сообщения

## Файлы для работы

- `modules/entities/messages/` - работа с сообщениями
- `modules/widgetes/chat/ChatInputWidget/` - виджет ввода сообщения
- `modules/entities/post/ui/Post/` - компоненты поста для отображения в сообщении

## UI для выбора поста

### В ChatInputWidget
- Кнопка "Прикрепить пост" или иконка
- Модальное окно или dropdown со списком постов
- Поиск постов
- Превью выбранного поста

### Компоненты
- `PostSelector.tsx` - компонент выбора поста
- `PostPreview.tsx` - превью поста перед отправкой

## Отображение поста в сообщении

### Тип сообщения
- Добавить тип сообщения `post` в enum типов сообщений
- Отображать пост как вложение к сообщению

### Компонент
- `MessagePost.tsx` - компонент для отображения поста в сообщении
- Компактный вид поста (миниатюра, заголовок, автор)
- Кликабельный для перехода к полному посту

## Переход к посту

- При клике на пост в сообщении - переход на страницу поста
- Использовать Next.js router для навигации
- Сохранять контекст чата (возможность вернуться)
